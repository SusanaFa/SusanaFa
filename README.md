## 💡 Proyectos destacados

### 🩺 SensorixFoot

MVP para el monitoreo de temperatura plantar, compuesto por una aplicación móvil en React Native y una plataforma web en React, con backend en Node.js y MongoDB.

- Autenticación mediante JWT.
- Gestión de pacientes y perfiles clínicos.
- Registro e historial de mediciones.
- Alertas basadas en rangos de temperatura.
- Integración con dispositivos BLE y ESP32 en desarrollo.

### 🐾 Entre Patas y Hogares

Plataforma orientada a facilitar la gestión de organizaciones de rescate y los procesos de adopción responsable de mascotas.

- API REST desarrollada con Java, Spring Boot y MongoDB.
- Gestión de mascotas, organizaciones y solicitudes de adopción.
- Historial médico, imágenes y solicitudes de ingreso.
- Validaciones y reglas de negocio por dominio.
- Frontend planificado como próxima etapa.

Repositorios:

- [API Entre Patas y Hogares](https://github.com/SusanaFa/api-entrepatas)
- [Entre Patas Domain](https://github.com/SusanaFa/entrepatas-domain)
